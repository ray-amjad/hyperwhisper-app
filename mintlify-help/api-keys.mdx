You can use your own API keys with HyperWhisper.

<Note>
  **You do not need an API key to use HyperWhisper.** By default, transcription runs on **HyperWhisper Cloud**. It works immediately after installation, and it needs no setup. Your first credit purchase (from \$5) creates an account key with **5,000 credits** (approximately \$5 of value — see [Providers](/choosing-a-provider)). HyperWhisper Cloud is **priced at face value with no markup**. You pay the same per-minute rate as a direct holder of the provider's API key.

  Use this page only if you want to send transcription or post-processing to your own provider account. For example, you have corporate credits, you have a free tier, or you want a model that Cloud does not offer.
</Note>

HyperWhisper keeps your keys on your device. It uses each key only for requests to the API endpoints of that provider. For example, HyperWhisper sends an OpenAI API key only to OpenAI. It sends your keys to no other destination.

### ElevenLabs

When you create your ElevenLabs API key, enable these permissions:

- **Speech to Text** — necessary for Scribe transcription
- **Models** — necessary for the model availability checks

Without these permissions, transcription fails, even when your API key is valid.

<Warning>
  Do not set a credit limit on your API key. Keep the credit limit field empty. A credit limit of 0 blocks all requests, even when your account has credits.
</Warning>

### Gemini 3.5 Transcribe

**Gemini 3.5 Transcribe** has its own key slot, next to **Google Gemini**. Get the key at [aistudio.google.com/apikey](https://aistudio.google.com/apikey) — the same page as Gemini.

<Warning>
  Put the key in the **Gemini 3.5 Transcribe** slot. A key in the **Google Gemini** slot does not operate Gemini 3.5 Transcribe. The two slots are separate, because the two products use different endpoints of Google.
</Warning>

### Meta Muse Voice Transcribe

Get a Meta Model API key from [Meta for Developers](https://dev.meta.ai/docs/speech-to-text/). Add it to the **Meta** slot in **Model Library → API Keys**.

The key stays in your operating system's secure credential store. A direct Meta mode sends its normalized WAV file from your device to `api.meta.ai`. It does not send the request through HyperWhisper Cloud and does not use HyperWhisper credits.

HyperWhisper does not make a hidden audio request to test the key. The app reports the key as configured and validates it on your first transcription.

Gemini 3.5 Transcribe is a speech model. You use it for transcription and for [streaming transcription](/streaming-settings). You cannot use it for post-processing. Use **Google Gemini** for post-processing.
